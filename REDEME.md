# Retail Sales Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset using Python.

## Objectives

- Analyze customer purchasing behavior
- Study monthly and quarterly sales trends
- Compare product category performance
- Understand customer demographics
- Generate business insights

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data Cleaning
- Descriptive Statistics
- Monthly Sales Analysis
- Quarterly Sales Analysis
- Age Group Analysis
- Gender Analysis
- Product Category Analysis
- Correlation Heatmap
- Revenue by Gender
- Key Business Insights
- Conclusion

## Project Files

- `EDA_Retail_Sales_Analysis.ipynb` – Complete analysis notebook
- `retail_sales_dataset.csv` – Dataset used for analysis
