# Data Analytics Project – Retail Sales Analysis

## 📌 Project Overview

This project focuses on analyzing a retail sales dataset using Python and data analytics techniques.

The main objective is to clean, explore, analyze, and visualize the data to identify useful patterns and insights related to sales, customers, products, and revenue.

## 🎯 Objectives

* Perform data cleaning and preprocessing.
* Conduct Exploratory Data Analysis (EDA).
* Analyze sales and revenue patterns.
* Examine relationships between numerical variables.
* Perform correlation analysis.
* Create meaningful data visualizations.
* Compare total revenue generated by different gender groups.
* Extract useful business insights from the dataset.

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📊 Analysis Performed

### 1. Data Loading

The retail sales dataset was imported using Pandas and examined to understand its structure.

### 2. Data Cleaning

The dataset was checked for:

* Missing values
* Duplicate records
* Incorrect data types
* Inconsistent values

### 3. Exploratory Data Analysis

EDA was performed to understand:

* Dataset dimensions
* Numerical and categorical variables
* Sales distribution
* Customer characteristics
* Revenue patterns

### 4. Correlation Analysis

A correlation matrix and heatmap were created to examine relationships between numerical variables.

The heatmap helps identify variables that have stronger positive or negative relationships with each other.

### 5. Additional Visualization

An additional bar chart was created to compare the total revenue generated by different gender groups.

The analysis was performed using:

```python
gender_sales = df.groupby('Gender')['Total Amount'].sum().sort_values(ascending=False)
```

The results were visualized using a bar chart titled:

**Total Revenue by Gender**

## 📈 Key Insights

The analysis helps identify differences in revenue contribution between gender groups and provides a better understanding of customer purchasing patterns.

The correlation analysis also helps identify relationships between numerical variables that may be useful for further business analysis.
